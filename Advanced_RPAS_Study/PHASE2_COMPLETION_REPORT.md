## Lessons Learned

1. **Staged Approach Effective:** Breaking Phase 2 into 2A (quick wins) → 2B (medium) → 2C (advanced) maintained momentum and allowed flexibility in question generation.

2. **Source-Driven Generation:** Using TP 15263 learning objectives and gold-source documents (RPAS 101, AIM, NAV CANADA) ensured question relevance and accuracy.

3. **Category Mapping Critical:** Organizing questions by TP 15263 sections (5=Navigation, 6=Flight Ops, 8=Radio) made it clear which categories needed improvement.

4. **Balance Required:** Mixing easy/medium/hard/tricky questions within each stage ensured comprehensive coverage without overwhelming learners.

5. **Quality Over Quantity:** While Phase 2 aimed for +161 questions, generating +114 high-quality questions was more valuable than padding with mediocre content.
