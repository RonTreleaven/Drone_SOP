# Advanced RPAS Study

Canonical working dataset for Canadian Advanced RPAS exam preparation.

## Folders

- `data/` — structured JSON datasets
- `notes/` — study-guide notes and reference summaries
- `archive/` — retired or superseded data
- root HTML files — future GitHub Pages study application

## Core datasets

- `references.json` — source library
- `categories.json` — knowledge-domain taxonomy
- `questions.json` — exam-like question bank
- `progress.json` — private learner performance/mastery data

## Publication model

**OneDrive = canonical working dataset**

**GitHub Pages = public study application / non-personal content**

Do not publish `progress.json` unless intentionally anonymized.
