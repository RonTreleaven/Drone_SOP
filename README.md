## Airspace Data Maintenance

`gcode.html` relies on:

- `data/canadian_airspace.geojson`

This file is generated by:

- `scripts/build_canadian_airspace_geojson.py`

Standard refresh command:

```powershell
python scripts/build_canadian_airspace_geojson.py --input ca_asp.geojson --output data/canadian_airspace.geojson --classes B,C,D,E,F
```

Maintenance guidance:

- Minimum refresh interval: every 6 months
- Better target: monthly or whenever source data is refreshed
- Final operational verification remains NAV CANADA DSST
