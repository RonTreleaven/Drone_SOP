GSD Quick Reference + Calculator

Ground Sampling Distance (GSD) is the real-world ground size represented by one image pixel.

GSD = (H x Sw) / (f x Iw)

Where H = height above ground (m), Sw = sensor width (mm), f = focal length (mm), Iw = image width (pixels). Convert m to mm before using formula.

Lower GSD is better detail. Example: 2.4 cm/pixel resolves smaller features than 4.8 cm/pixel.
